## 2. 레퍼런스 락
- **주 레퍼런스: Bezel** (`ref-bezel-s00~s08`, `lot-bezelauc-s00~s44`) — 깔끔·고급 + 초록 + 마켓플레이스 + 경매를 한 사이트가 다 가진 유일한 레퍼런스.
- **보존(5)**
  1. 짙은 초록 헤더 막대 안에 검색창 + 오른쪽 메뉴, 본문은 흰 바탕 (Bezel #061A11 / #FFFCF9 실측)
  2. 그로테스크 한 벌, 굵기 400·500 두 개, 제목 자간 -0.025em, 글자 크기 8종 이하 (Bezel 실측 8종)
  3. 상품 칸 = 사진 타일(모서리 16) + 브랜드 대문자 작게 + 이름 + 가격, 경매 상품은 사진 위 "Auction" 알약
  4. 경매 띠 = 초록 바탕 섹션 + 카드 안 BID / ENDS IN 두 칸 + 카운트다운 숫자
  5. 홈 순서 = 사실 히어로 → 상품 → 신뢰 모듈(체크 칩) → 브랜드 타일(개수) → 경매 띠 → Why 3칸 → 푸터(밝은 바탕 4열)
- **차용(2)**
  - WGACA·Fashionphile·Rebag·1stDibs — 흰 카테고리 줄(헤더 아래 한 줄) + 흰 배경 누끼 상품을 연회색 타일에 올리는 처리. 우리 사진이 전부 흰 배경 누끼라서(실재고 40장 대조) 이 처리가 그대로 맞는다.
  - Loupe This 상세(`lot-loupe-s00`) — 오른쪽 칸 맨 위 "Current bid | Auction ends" 한 줄 + Lot 번호 · Save + 꽉 찬 알약 버튼 "Register to bid".
- **역할 규칙**: 짙은 초록 = 헤더·히어로·경매 띠·주 버튼에만. 민트(#34D399, Bezel 실측) = 어두운 초록 위 카운트다운에만. 빨강 = 마감 1시간 전(더윈 12)에만. 알약(완전 둥근) = 버튼·칩·상태 알약에만.
- **거부**: 미색 바탕, 세리프 이탤릭 눈썹, 로마 숫자, 금색, 왼쪽 강조 줄, 생성 사진을 주인공으로, 대문자 자간 라벨 남발, 카드마다 두꺼운 색 띠.
- **매체**: 히어로 = 실재고 사진 4장을 배경 제거해 초록 위에(Bezel 히어로의 상품-on-초록). 나머지는 실재고 사진 그대로. 힉스필드 생성 사진은 how-it-works 의 '단단한 상자 포장'(더윈 8) 설명 한 곳만.
